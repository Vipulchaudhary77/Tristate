# Tri-State Stone — Premium Marketing Website

Luxury marketing website for **Tri-State Stone Granite & Cabinets Inc**, built with Next.js 15, React, TypeScript, Tailwind CSS v4, Framer Motion, GSAP, Lenis, and shadcn/ui.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Project Structure

- `src/app/` — App Router pages (40 static routes)
- `src/components/sections/` — Homepage sections
- `src/components/layout/` — Navbar, footer, floating actions
- `src/components/shared/` — GoldButton, GlassCard, MasonryGallery, etc.
- `src/lib/data/` — Content modules (easy to swap placeholders)
- `public/brand/logo.png` — Company logo

## Features

- Full luxury homepage with 15 sections
- Mega-menu navigation with all stone, service, and gallery routes
- Dark/light mode, Lenis smooth scroll, GSAP scroll animations
- Pinterest-style gallery with lightbox and before/after slider
- Contact form with validation, Google Maps embed, WhatsApp
- SEO metadata + JSON-LD schema (LocalBusiness, FAQPage)

## Customizing Content

Edit files in `src/lib/data/` to replace placeholder copy, images, and contact details.

## Tech Stack

Next.js 15 · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · GSAP · Lenis · shadcn/ui
